# Noise-Robust AE Classification

Reproducible implementation for **denoising-assisted acoustic-emission (AE) damage-mode classification in concrete structures** under field-recorded bridge-noise contamination.

The workflow includes:

- preparation of tensile- and shear-test AE datasets;
- separation of normal-traffic and heavy-truck noise pools;
- controlled noise synthesis at 0, 5, 10, and 15 dB;
- training of the one-dimensional denoising network;
- training of clean-signal and noise-augmented classifiers;
- conventional denoising baselines and architectural ablations;
- signal-reconstruction and classification evaluation;
- computational-cost benchmarking; and
- generation of the figures reported in the manuscript.

Extract the downloaded data into the `data` directory:

```text
data/
├── jian/
├── jian_test/
├── la/
├── la_test/
├── normal_noise.npy
└── truck_noise.npy
```

In the filenames used by the code:

- `jian` denotes the shear-dominated test group and is assigned class `0`;
- `la` denotes the tensile-dominated test group and is assigned class `1`.

The labels represent the dominant test/specimen-level damage mode. They are not independently verified event-level fracture-mechanism labels.

## Reproduction workflow

Run `AE-noise-classification-github.ipynb` from top to bottom. The major stages are described below.

### 1. Data preparation

The waveform files from the four source directories are concatenated to produce:

```text
jian_all.npy
la_all.npy
jian_test_all.npy
la_test_all.npy
```

Each waveform contains 1,024 time-domain samples.

### 2. Bridge-noise partitioning

The normal-traffic and heavy-truck noise libraries are separately shuffled and divided into mutually exclusive indexed pools at an 8:1:1 ratio:

```text
normal_noise_train.npy
normal_noise_val.npy
normal_noise_test.npy
truck_noise_train.npy
truck_noise_val.npy
truck_noise_test.npy
```

Noise is sampled with replacement within each pool because the number of AE waveforms exceeds the number of available noise segments. A noise segment assigned to one indexed pool is not used in either of the other pools.

### 3. Clean-waveform partitioning and noise synthesis

For every random seed, the original clean AE waveforms are divided into mutually exclusive training and validation subsets at a ratio of 9:1 **before** noise contamination. Consequently, noisy versions derived from one clean waveform remain in the same subset.

Noise is scaled according to the desired power-based SNR:

```text
0, 5, 10, and 15 dB
```

At each SNR, each clean waveform generates two contaminated samples: one using normal-traffic noise and one using heavy-truck noise.

### 4. Denoising-model training

The denoising backbone is a seven-block one-dimensional convolutional encoder–decoder with skip connections. Encoder filter counts are:

```text
16, 32, 64, 128, 256, 512, 1024
```

The bottleneck contains 1,024 filters. The models are trained with noisy waveforms as inputs and clean waveforms as targets using Adam optimization and mean-squared-error loss.

Training is repeated for four SNR levels and ten random seeds:

```text
42, 123, 2024, 7, 19, 66, 88, 100, 256, 512
```

This produces 40 denoising models. Each model is trained for 100 epochs with a batch size of 2,000, and the model state with the lowest validation loss is retained.

### 5. Classification-model training

The classifier is a fully connected network containing three hidden layers with 1,024 ReLU units per layer and a sigmoid output unit. It is trained using Adam with a learning rate of `1e-3` and binary cross-entropy loss.

The notebook evaluates:

- a classifier trained using clean AE signals;
- direct classification of noise-contaminated test signals;
- classification after waveform denoising; and
- classifiers trained directly using noise-augmented AE signals.

### 6. Baselines and ablations

The supplied implementation includes the following comparisons:

- non-denoised input;
- FFT-based denoising;
- five-level `db8` wavelet soft-threshold denoising;
- convolutional encoder–decoder without skip connections;
- fully connected autoencoder variant; and
- direct noise-augmented classification.

The learned models and conventional baselines are evaluated using the same test waveforms and noise conditions wherever applicable.

### 7. Evaluation

Signal reconstruction is evaluated using:

- output SNR;
- Pearson correlation coefficient;
- normalized root-mean-square error (NRMSE); and
- log-spectral distance.

Classification evaluation includes:

- confusion matrix;
- accuracy;
- precision;
- recall;
- F1 score;
- specificity; and
- area under the ROC curve, where applicable.

Reported bars and error bars represent the mean and standard deviation across repeated models, as specified in the corresponding notebook section.

### 8. Computational benchmarking

The final notebook sections report:

- trainable parameter count;
- stored model size;
- GFLOPs per 1,024-point waveform;
- mean and 95th-percentile inference latency;
- throughput; and
- GPU memory usage.

The timing results cover model inference only and exclude acquisition, disk access, communication, and event-detection overhead.

## Reproducibility notes

- Run the global path-configuration cell before all other cells.
- Run the data-preparation and noise-partitioning sections before model training.
- Do not mix previously generated files produced using different dataset partitions or model configurations.
- Model selection is performed using validation results only; the test set is reserved for final evaluation.
- The tested denoising benefit is concentrated at input SNRs of 0–5 dB. At 10 dB, the benefit is condition-dependent, while denoising may slightly distort some already high-quality signals at 15 dB.
- Results from the reinforced-concrete girder provide quantitative evidence for denoising but only qualitative agreement for classification because event-level ground-truth damage labels are unavailable.
